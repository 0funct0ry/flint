Flint is the local-first Markdown IDE for the context files your AI tools already read —
`CLAUDE.md`, specs, project notes. Point it at a directory, and it gives you an editor, a reader,
link navigation, search, and backlinks on top of the plain `.md` files already there. It owns no
data and makes no network requests, ever.

## Start here

- **[Getting Started](/flint/docs/getting-started/)** — install Flint, run `flint init`, and open
  your first workspace.
- **[Concepts](/flint/docs/concepts/)** — the five terms used everywhere in Flint: Workspace, Note,
  Folder, Link, Backlink.
